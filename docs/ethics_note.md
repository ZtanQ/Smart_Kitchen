# Nota de ética y acceso

## Origen y permisos

- Datos de productos: **OpenFoodFacts** (ODbL). Base abierta y colaborativa.
- No se realiza scraping de perfiles privados ni acceso a datos restringidos.

## Privacidad

Toda la capa de interacción (movimientos de cocina) es **sintética**,
generada por simulación estadística. No se utilizan datos de usuarios
reales en ningún momento del pipeline.
